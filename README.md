# Dijitsu Kumanda

Dijitsu Android TV'yi telefondan ADB (ağ hata ayıklama, port 5555) ile kontrol eden kumanda uygulaması.

- Yön tuşları, ses, kanal, güç, oynatma tuşları
- HDMI 1/2/3 ve giriş listesi
- Telefondan TV'ye yazı yazma, uygulama açma, favoriler
- Touchpad ve telefonun ses tuşlarıyla TV sesi
- Makrolar
